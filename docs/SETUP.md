# מדריך הקמה

הקמה חד פעמית, בערך חצי שעה. עושים את הכול מהמחשב. כפתורים ושמות באנגלית מופיעים בשורה נפרדת, כדי שיהיה קל להעתיק ולמצוא.

## שלב 1: מפתח לג'מיני

1. נכנסים לאתר הזה עם חשבון הגוגל:

```
https://aistudio.google.com/apikey
```

2. לוחצים על יצירת מפתח:

```
Create API key
```

3. מעתיקים את המפתח ושומרים אותו בצד. הוא יידרש בשלב 3.

## שלב 2: שירות הדיבור של מיקרוסופט

1. נכנסים לפורטל של מיקרוסופט ופותחים חשבון. בהרשמה נדרש כרטיס אשראי, אבל אין חיוב במסלול החינמי:

```
https://portal.azure.com
```

2. בחיפוש למעלה מקלידים את שם השירות ובוחרים ביצירה:

```
Speech services → Create
```

3. ממלאים:
   - קבוצת משאבים: יוצרים חדשה, למשל `reading`.
   - אזור: מומלץ מערב אירופה, הכי קרוב לישראל:

```
West Europe
```

   - שם: כל שם, למשל `aline-speech`.
   - מסלול תמחור: המסלול החינמי:

```
Free F0
```

4. לוחצים על יצירה ומחכים דקה. אחר כך נכנסים למשאב, ובתפריט הצד בוחרים:

```
Keys and Endpoint
```

5. מעתיקים את המפתח הראשון ואת האזור, ושומרים בצד. האזור נראה כך:

```
westeurope
```

6. **חשוב: אחרי 30 יום חשבון הניסיון נחסם, ושירות הדיבור מפסיק לעבוד.** כדי שזה לא יקרה, משדרגים את המנוי לתשלום לפי שימוש, עוד לפני שהחודש נגמר:

```
Subscriptions → Upgrade → Pay-As-You-Go
```

אין חיוב כל עוד השירות נשאר במסלול החינמי. במסלול הזה השירות פשוט מפסיק לענות כשהמכסה החודשית נגמרת. ליתר ביטחון אפשר להגדיר התראת תקציב של דולר אחד:

```
Cost Management → Budgets → Add
```

## שלב 3: הסקריפט של גוגל

משתמשים באותו פרויקט סקריפט שהקמנו בבדיקת המיקרופון.

1. פותחים את הפרויקט, ומוחקים את שני הקבצים הישנים: `Code.gs` ו־`Index.html`.

2. בהגדרות הפרויקט, בגלגל השיניים בצד, מסמנים את האפשרות להציג את קובץ ההגדרות:

```
Show "appsscript.json" manifest file in editor
```

3. חוזרים לעורך. פותחים את הקובץ `appsscript.json`, ומחליפים את כל התוכן שלו בתוכן של הקובץ מהמאגר:

```
server/appsscript.json
```

4. לכל קובץ בתיקייה `server` במאגר, יוצרים קובץ סקריפט בעורך, עם אותו שם בדיוק, ומדביקים לתוכו את התוכן. בעורך לוחצים על הפלוס ליד המילה "קבצים" ובוחרים סקריפט. את הסיומת העורך מוסיף לבד:

```
Auth  Logging  Mailer  Router  Scoring  Sessions  Settings  Setup  SpeechToken  Stories  Util
```

5. בהגדרות הפרויקט, למטה, מוסיפים ארבעה מאפייני סקריפט:

```
Script Properties → Add script property
```

| שם המאפיין | הערך |
| --- | --- |
| `GEMINI_API_KEY` | המפתח משלב 1 |
| `AZURE_SPEECH_KEY` | המפתח משלב 2 |
| `AZURE_SPEECH_REGION` | האזור משלב 2, למשל `westeurope` |
| `PAGE_URL` | `https://michael-shalamaev.github.io/Aline-Reading/` |

6. שומרים את ההגדרות.

## שלב 4: יצירת הגיליון ובדיקה

1. בעורך, בראש המסך, בוחרים את הפונקציה `setup` ולוחצים הרצה:

```
Run
```

2. בפעם הראשונה גוגל יבקש הרשאות: גיליונות, שליחת מייל ופנייה לשירותים חיצוניים. מאשרים. אם מופיעה אזהרה שהאפליקציה לא מאומתת, לוחצים:

```
Advanced → Go to ... (unsafe)
```

זו האזהרה הרגילה לסקריפט שכתבת לעצמך.

3. ביומן ההרצה בתחתית יופיעו הכתובת של הגיליון והקישור האישי של הילדה. נוצר גם גיליון בדרייב בשם "קריאה באנגלית: הגדרות ויומן".

4. בוחרים את הפונקציה `selfTest` ומריצים. כל השורות ביומן צריכות להיות ירוקות. אם יש שורה אדומה, שולחים לי אותה.

5. רשות: מריצים את `testStory`, כדי לראות סיפור לדוגמה ביומן, בלי לשמור כלום.

## שלב 5: פרסום הסקריפט

חשוב לעדכן את הפריסה הקיימת ולא ליצור חדשה, כדי שהכתובת לא תשתנה:

```
Deploy → Manage deployments → ✏️ → Version: New version → Deploy
```

לוודא שבהגדרות הפריסה מופיע:

```
Execute as: Me
Who has access: Anyone
```

## שלב 6: העלאה לאוויר

1. מאשרים את בקשת המיזוג בגיטהאב. אחרי דקה או שתיים העמוד מתעדכן.
2. בגיליון, בלשונית "הגדרות", מעתיקים את הקישור האישי מהשורה `link`.
3. פותחים אותו בכרום בטלפון של הילדה, ובתפריט בוחרים הוספה למסך הבית.

## שלב 7: התקנה כאפליקציה ושעות בלי הגבלה

המטרה: שהקריאה לא תיספר מהשעה היומית שלה, ושתהיה זמינה גם אחרי שהשעה נגמרה.

1. בטלפון שלה, פותחים בכרום את הקישור האישי מהגיליון. זה חשוב: האפליקציה זוכרת מהפתיחה הזו מי הילדה.
2. בתפריט של כרום, בשלוש הנקודות, בוחרים התקנה. אם מופיעה רק הוספה למסך הבית, בוחרים אותה ואז "התקנה":

```
Install app  /  Add to home screen → Install
```

3. נפתחת אפליקציה בשם "קוראים", עם אייקון של ספר. פותחים אותה פעם אחת ומאשרים מיקרופון.
4. בממשק ההורים של גוגל, בטלפון שלך: בוחרים את הילדה, נכנסים להגבלות האפליקציות, מוצאים את "קוראים" ומסמנים שהיא תמיד מותרת:

```
Controls → App limits → קוראים → Always allowed
```

5. **בדיקה שחובה לעשות:** ביום שהשעה שלה נגמרה, לוודא שהאפליקציה עדיין נפתחת ושהמיקרופון עובד. האפליקציה מותקנת בנפרד, אבל היא רצה על המנוע של כרום, ולא וידאנו שממשק ההורים מפריד ביניהן.

אם האפליקציה לא מופיעה ברשימה, או ננעלת יחד עם כרום, נחזור לכלל "קודם קוראים" ולבונוס ידני.
